# 日常更新模块来源

覆盖状态：partial。实现模式：hybrid。来源类型：W/U/E/A。

- W：《公司电商数据仓库架构与使用指南》《tbcli 与数据仓库扩展协作协议》提供元命令、权限、覆盖记录与事务边界；编译时去除私人路径和凭证配置。
- U：日常清单随插件分发；只维护近期而非历史起始日差异；CLI 不决定业务范围；当前仅维护者有写权限；本阶段只补缺不默认回刷。
- U/E（2026-09-04）：用户确认旺店通订单、明细、运单和退款进入同一日常 Skill并每日更新；当前实现以最近 45 个完整自然日为状态回溯基线。退款真实初始批次已覆盖 2026-07-01~2026-09-03，共 11,890 头、15,975 明细并通过覆盖闭合验证。
- U/E（2026-09-04）：用户确认每日预估利润只在推广费已出数日期计算；收入按有效订单支付日，退款按结算日，成本与运费按已确认优先级估算，负责人来自 `master.product_owner_versions`。用户已接受三位运营最近 7 天的全中文 Excel 作为应用层标准样例；真实导出已验证多人精确筛选、五张工作表、利润率、中文字段和日期回执。
- U/W/E（2026-09-23）：用户确认利润分为月中预估与次月实际两类。实际利润在取得实际快递账单和实际退款事实后运行；计算方法与数据缺口检查分离，缺口可以后续补齐或使用另行确认的估算政策。正式方法编译自月度经营利润、旺店通订单退款契约、快递账单与主数据治理知识；CLI 已验证订单、退款、快递、预估利润、只读 `profit actual coverage` 以及按全店、负责人、商品和报告数据包汇总的 `profit actual query`，实际利润 Excel `export` 仍以实时能力清单为准。
- U（2026-09-23）：`operating-profit-v1` 的平台费率固定为6%、税率固定为2%；未匹配实际账单的运单按每单2元估算并在利润报告中单列估算金额；成本缺失逐项列出等待确认；利润计算不在数据库保存快照，计算完成后生成分析报告。
- U/E（2026-09-23）：用户确认负责人归属于商品 ID；成本一致性审计与运营分摊分开处理。成本审计逐订单行核对旺店通 `goodsCost`、`refCostPrice × skuNum` 与支付日有效的已批准 SKU 成本版本乘数量，不能只用合计判断一致。
- U/E（2026-09-23）：用户选择 `raw.wdt_order_headers.paid_amount` 作为实际利润收入总额；WDT商品明细 `shareAmount/paid` 仅作为订单内归一化分配权重。商品 `641773251256` 是补差价链接，无需负责人且没有商品成本，记录为 `explicit_zero`，不作为成本或负责人缺口。
- U/E（2026-09-23）：用户提供定期维护的商品 ID—商品图片映射表，并确认数据库表以商品 ID 为唯一键；图片变化通过重新导入修正。CLI 校验固定四列、商品 ID 唯一和 HTTPS 链接，再以 upsert 写入权威主图映射；利润报告不再从其他来源猜测商品图。
- U（2026-08-31）：用户明确单店范围时，不因 CLI 身份元数据缺失阻塞下载；采用用户确认的下载前范围与真实 Excel 的入库前店铺校验。具体店铺名留在任务输入，不作为其他安装环境的默认事实。
- E：当前 tbcli 的 coverage 同时读取事实日期和 import_files 声明区间；replace-range 是单片事务；installer 递归复制/链接整个伴生 Skill。
- E：新增 maintenance 元命令只持久记录调用者显式计划，不请求淘宝、不执行数据库写入、不决定缺失日期。
- E（2026-09-01）：Codex/macOS 真实维护者 main-run 已完成 19 张取数报表的当前可取范围补缺、Excel 身份 QA、原子入库和整表 coverage 闭合；平台待出数仍以 partial 披露。
- A：平台更新延迟、无界归因变化的回刷长度、生产定时执行时刻尚待实测；不得把15天转化直接当作回刷政策。

关键缺口：SealSeek/Windows 上本版本执行、旺店通网页登录长期稳定性、订单/退款变更的回刷窗口、跨机器防并发、备份恢复；月度实际利润 Excel `export` 和商品重量主数据覆盖仍需实现。当前没有使用重量分摊，按已确认政策将订单运费按订单内归一化收入占比分配。`profit actual coverage` 已能核对按原订单支付月与截止日结算退款、实际运单账单匹配及现有主数据覆盖；`profit actual query --group-by report` 已在真实 7 月数据上完成全店总额回勾。当前要求单维护机器单运行目录，不宣称分布式互斥。
