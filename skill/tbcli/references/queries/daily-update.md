# 入口：补全日常维护表或检查近期缺口

适用：“帮我补全取数报表近期缺失数据”“只增补商品-整体和无界-账户”“检查缺失日期，暂不入库”“继续上次失败的更新”。

按顺序完整读取：

1. [唯一维护清单](../report-maintenance.md)：确定哪些表、什么口径、何种粒度。
2. [日常执行主线](../daily-update.md)：确定只检查或实际更新、日期规则、权限和失败边界。
3. [运行记录协议](../maintenance-run-contract.md)：实际更新时记录计划、锁和回执；只检查模式只需理解其不写状态的限制。

返回主 Skill 的 Daily Update 模块执行，不进入普通取数的通用终端映射。
历史全量重建不走日常补缺，返回 report-maintenance.md 的明确授权分支。
