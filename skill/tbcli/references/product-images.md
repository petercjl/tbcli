# 商品主图映射

本页用于维护商品 ID 到权威商品主图链接的稳定映射。利润计算不依赖图片，但商品级分析报告使用该映射渲染远程缩略图。

## 输入契约

Excel 只包含一个工作表，首行严格为：`商品ID`、`商品标题`、`图片链接`、`商品类目`。

- 商品 ID 必须是纯数字，并在整个文件内唯一。
- 商品标题、图片链接和商品类目不能为空。
- 图片链接必须是 HTTPS；CLI 只保存链接，不下载或嵌入图片。
- 调用者必须明确提供店铺键和店铺名称。

先校验：

```bash
tbcli product images validate --input '<映射表.xlsx>' --shop-key '<店铺键>' --shop-name '<店铺名称>' --json
```

校验通过且调用者拥有维护权限后导入：

```bash
tbcli product images import --input '<映射表.xlsx>' --shop-key '<店铺键>' --shop-name '<店铺名称>' --json
```

## 写入与更新语义

`master.product_image_mappings` 以 `platform_product_id` 为唯一键。首次导入新增记录；后续导入对相同商品 ID 更新标题、图片链接、类目、店铺元数据和来源信息。当前文件没有出现的历史商品不自动删除。

导入结果必须返回新增、更新、未变化数量，以及源文件名和 SHA-256。任何行校验失败时整份文件不得入库；数据库写入在一个事务内完成，失败时回滚。

月度实际利润查询只从该权威映射表返回 `product_image_url`。没有映射的商品保持空值，由应用层报告显示缺图状态，不使用其他来源猜测图片。
